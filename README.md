# Breathing Box (Android)

A WebView wrapper around the Breathing Box page. The page lives in
`app/src/main/assets/index.html`, so edit that file to change the app.

## Get the APK
1. Create a new GitHub repository and upload everything in this folder
   (keep the `.github` folder).
2. Open the repository's **Actions** tab. The "Build APK" run starts on its own
   (or use "Run workflow").
3. When it turns green, open the run and download **breathing-box-apk**.
4. Unzip it and copy `app-debug.apk` to your phone, then open it to install.
   Android will ask you to allow installs from your file manager or browser.
